# Decodificador Draco local

Archivos oficiales obtenidos de `https://cdn.babylonjs.com/v9.25.0/` para la carga de GLB con `KHR_draco_mesh_compression`.

- `draco_wasm_wrapper_gltf.js`
- `draco_decoder_gltf.wasm`

Proyecto original: Google Draco, https://github.com/google/draco (licencia Apache 2.0). Se conservan localmente para evitar peticiones a un CDN durante el juego. La configuración usa un único trabajador de decodificación.
