# Recuerdos

Reservado para fotografías y audios de recuerdos. Las seis historias están definidas en `src/content/stories.ts`; el lector y sus ilustraciones locales están en `src/presentation/memories/`. Cada historia tiene tres páginas y un identificador estable para conservar su estado en las partidas.

Los recursos de esta carpeta son públicos al publicar la web. Para recuerdos privados se necesita autorización en el servidor antes de entregar el contenido.
