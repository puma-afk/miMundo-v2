# Ajuste de pistas y respuesta

Las primeras tres pistas se guardan automáticamente al llegar a la tercera página. Si falla el guardado, el botón permite reintentar. Los objetos adelantados indican el objeto pendiente y no muestran una historia genérica que confunda el recorrido.

La última pregunta es «¿Aceptas?». El campo admite 500 caracteres y se guarda explícitamente dentro de giftProgress.response, junto con el progreso local y la sincronización de cuenta existente. No envía mensajes ni notificaciones. No mostrar este campo en futuras visitas públicas: contiene una respuesta privada. La vista previa conserva su almacenamiento separado.

Las tarjetas usan ilustraciones más compactas en celular, texto de 16 px y controles de al menos 44 px. El teclado del campo de respuesta no cambia de página con las flechas.

Pendiente: identificar el campo URL que Cloudflare solicita al propietario; aún no se publica ni se configura Google. La carpeta de entrega antigua sigue desactualizada.
